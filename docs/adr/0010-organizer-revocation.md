# PlatformAdmin 可撤除 Organizer 資格,且無法自助恢復

SoundArena 是開放多租戶平台(ADR-0002):任何人完成一次性的主辦人身分檔案設定就能自助成為 Organizer,不需要審核。使用者要求保留這個自助流程,但同時要有事後把關手段——PlatformAdmin 遇到濫用 Organizer 身分的情況時,能直接收回對方的管理權限。

**決定**:新增 `OrganizerRevocation`,用時間戳記(`host_revoked_at`)而不是把既有的 `host_setup_completed` 布林值反轉。原因:兩者要導向不同畫面——「從沒設定過」該看到設定表單,「設定過但被撤除」不該再看到表單(否則等於自己重新走一次自助流程就恢復了,跟撤除的初衷矛盾),而是要看到「已被撤除」的說明畫面。撤除範圍是這個人的**全部** Organizer 管理權限(含既有比賽),不是只擋新建比賽;但不影響他以一般使用者身份參賽,也不影響他已建立比賽的公開內容。只有 PlatformAdmin 能重新賦予,被撤除的人自己無法解除。

**已知限制**:被撤除的 Organizer 若有比賽正在進行中(有 Collaborator、有待審核的報名/投稿),撤除後這些事務沒有自動轉交機制,需要 PlatformAdmin 手動處理(例如邀請自己成為該比賽的 Collaborator)。這一輪沒有做自動化轉移,留給之後真的遇到才處理。
